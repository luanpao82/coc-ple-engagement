1 · Manual coding merged, and the FY2022 crosswalk verified

Coauthor manual coding of the remediation files (anti_criminalization_manual_coding.xlsx) is merged into the raw data by 01_merge_manual_coding.R. The merge fills 383 cells across 24 CoC-years. Twenty cells that the automated extractor had also captured matched the manual values exactly — an incidental cross-validation — and the single conflict (OR-500, 2023, item 1d_10c) resolves in favor of the manual transcription, with every change recorded in a cell-level merge log.

The FY2022 1D-11a crosswalk
The FY2022 1D-11a participation table has five rows whose order does not align with the four-row FY2023–FY2024 table. The pipeline's semantic crosswalk (row 4 → decision-making, 3 → committees, 5 → rating factors; coordinated entry structurally absent in FY2022) was confirmed against extract_pdf_native.py, and the manual-coding merge now applies the same mapping. The 158 missing values on 1d_10a_4_* are therefore structural (no such question in FY2022), not extraction failures.

2 · From raw data to the analysis panel

  1. 01_merge_manual_coding.R — merges the manual coding into the raw data (383 cells, 24 CoC-years) and applies the FY2022 crosswalk.
  2. 02_build_panel.R — assembles the 650 × 320 panel: duplicate docx/pdf pairs removed (8), Special-NOFO applications excluded (19, all FY2022), pure Yes/No recoded to 1/0, and per-CoC panel flags (n_years, balanced) added.
  3. 03_construct_variables.R — constructs the model-role variables: the DV (crim_activity_index), the PLE-engagement counts (with a three-item common-core sum comparable across years), the leadership classification, and the HUD PIT size control.

3 · Size control: HUD PIT counts

Point-in-Time (PIT) homeless counts are merged as a size control from the HUD 2007-2024-PIT-Counts-by-CoC.xlsx file. The match succeeds for 647 of 650 CoC-years. Three rows fail because their CoC numbers are absent from the HUD PIT file in those years and are flagged for review:

CoCYear(s)Reason
MA-5192 yearsCoC number absent from HUD PIT file
MD-5092022CoC number absent from HUD PIT file

Following a numerator/denominator-separation logic, the main specification uses log(participation count) with log(PIT) as a control; ratio versions of the engagement measures are retained only for robustness.

1 · 수기 코딩 병합과 FY2022 크로스워크 검증

보강 파일(anti_criminalization_manual_coding.xlsx)에 대한 공저자 수기 코딩을 01_merge_manual_coding.R로 원자료에 병합합니다. 이 병합은 24 CoC-연도에 걸쳐 383개 셀을 채웁니다. 자동 추출기가 함께 잡아낸 20개 셀은 수기 값과 정확히 일치했고(부수적 교차검증), 유일한 충돌 (OR-500, 2023, 항목 1d_10c)은 수기 전사를 채택하며, 모든 변경은 셀 단위 병합 로그에 기록됩니다.

FY2022 1D-11a 크로스워크
FY2022 1D-11a 참여 표는 5개 행의 순서가 FY2023–FY2024의 4행 표와 정렬되지 않습니다. 파이프라인의 의미 기반 크로스워크(행 4 → 의사결정, 3 → 위원회, 5 → 평가요인; coordinated entry는 FY2022에 구조적으로 부재)를 extract_pdf_native.py와 대조해 확인했고, 수기 코딩 병합도 동일한 매핑을 적용합니다. 따라서 1d_10a_4_*의 결측 158개는 추출 실패가 아니라 구조적(FY2022에는 해당 문항 없음)입니다.

2 · 원자료에서 분석 패널까지

  1. 01_merge_manual_coding.R — 수기 코딩을 원자료에 병합(383셀, 24 CoC-연도)하고 FY2022 크로스워크를 적용.
  2. 02_build_panel.R — 650 × 320 패널 구성: 중복 docx/pdf 쌍 제거(8), Special-NOFO 신청 제외(19, 전부 FY2022), 순수 Yes/No를 1/0으로 재코딩, CoC별 패널 플래그(n_years, balanced) 추가.
  3. 03_construct_variables.R — 모델 역할 변수 구성: DV(crim_activity_index), PLE 참여 수(연도 간 비교 가능한 3개 항목 공통핵심 합 포함), 리더십 분류, HUD PIT 규모 통제변수.

3 · 규모 통제변수: HUD PIT 카운트

Point-in-Time(PIT) 노숙 카운트를 HUD 2007-2024-PIT-Counts-by-CoC.xlsx 파일에서 규모 통제변수로 병합합니다. 매칭은 650 중 647 CoC-연도에서 성공합니다. 3개 행은 해당 연도 HUD PIT 파일에 CoC 번호가 없어 실패했고 검토용으로 플래그됩니다:

CoC연도사유
MA-5192개 연도HUD PIT 파일에 CoC 번호 없음
MD-5092022HUD PIT 파일에 CoC 번호 없음

분자/분모 분리 논리에 따라, 주 사양은 log(참여 수)에 log(PIT)를 통제변수로 사용합니다; 참여 측정치의 비율 버전은 강건성 확인용으로만 유지됩니다.
