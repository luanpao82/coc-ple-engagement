# CoC PLE Engagement — companion site

Standalone companion site for the study **"From Inclusion to Influence: How CoC
Governance Shapes Engagement with People with Lived Experience (PLE) and Local
Responses to Homelessness Criminalization"** (Lee, Kim & An, University of Central
Florida).

**Live site:** https://luanpao82.github.io/coc-ple-engagement/

A bilingual (English / 한국어) status site — use the language toggle at the top of
any page:

- **Overview** — research question and framework
- **Data & pipeline** — from HUD CoC application documents to a 650 × 320 analysis panel
- **Measurement** — the DV, PLE-engagement measures, and the 15-indicator coding schema
- **Descriptive statistics** — verified distributions (read from the R pipeline output)
- **PLE narrative coding** — full-corpus coding of 620 CoC-years, validated against the pilot
- **Results** — the panel model (PLE engagement → anti-criminalization activity, moderated by CoC leadership)
- **Status** — what is done and what remains

The pages are static HTML; every figure was verified against the R analysis
pipeline before publishing. This site is separate from the main
`coc-criminalization` project repository.
